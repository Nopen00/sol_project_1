# Drone Weather & Airspace Risk Map

**드론 비행을 위한 기상 위험도 및 공역 규제정보 시각화 웹 서비스**

카카오맵과 FastAPI를 활용하여 대한민국의 드론 비행 관련 정보를 지도 위에 시각화하는 프로젝트입니다.

기상청 API에서 제공하는 기상정보를 활용해 격자별 기상 위험도를 표현하고, 비행금지구역·비행제한구역·관제권 정보를 함께 표시하여 사용자가 특정 지역의 비행 환경을 직관적으로 확인할 수 있도록 구현했습니다.

## 주요 기능

- **카카오맵 기반 지도:** 대한민국 중심의 지도 탐색 및 확대·축소
- **기상 위험도 시각화:** 기상정보를 분석하여 주의·경고·위험 단계별 격자 색상 표시
- **공역 규제정보 표시:** 비행금지구역, 비행제한구역 및 관제권을 격자에 반영
- **지역별 탐색:** 시·도 및 시·군·구 선택 기능
- **사용자 인터페이스:** 사이드바 제어, 공역 표시 전환, 전국 지도 초기화
- **데이터 처리:** 기상정보 조회, 위험도 계산 및 캐싱을 통한 반복 요청 관리

## 기술 스택

| 구분 | 기술 |
|---|---|
| Backend | Python, FastAPI |
| Frontend | HTML, CSS, JavaScript |
| Map | Kakao Maps JavaScript SDK |
| Weather Data | 기상청 공공데이터 API |
| Geospatial Data | GeoJSON |
| Server | Uvicorn |

## 프로젝트 목적

드론 비행 시 고려해야 할 기상 위험정보와 공역 규제정보를 하나의 지도에서 확인할 수 있도록 통합하는 것이 목적입니다.

단순한 기상정보 제공을 넘어 공간 격자를 활용한 위험정보 시각화와 사용자 중심의 지도 탐색 기능을 구현하는 데 중점을 두었습니다.

## 안내

본 프로젝트는 학습 및 포트폴리오 목적으로 제작되었습니다. 표시된 기상 위험도와 공역 정보는 참고용이며, 실제 드론 비행 전에는 최신 공식 공역정보와 비행 승인 필요 여부를 별도로 확인해야 합니다.
